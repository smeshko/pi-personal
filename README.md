# pi-personal

Pi package with personal-only resources. Loaded together with `~/Developer/pi-core`.
Same layout as pi-core: `extensions/`, `prompts/`, `agents/`, `mcp.json`. No skills: all skills live in
~/.dotfiles (`agents/skills/` → `~/.agents/skills`, which pi reads).
Servers and agents here override pi-core entries with the same name.
